# Soldat Remake

A browser remake of the 2D shooter Soldat, with the original physics and weapon values and a winter art style.

## Stack

Plain HTML + Canvas 2D + JavaScript in a single `index.html`. No build step and no dependencies.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8123
```

## Environment variables

None.
